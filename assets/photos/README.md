# Fotografiile Mokum

Pune aici fotografiile reale Mokum (JPG, ideal 2000 px pe latura lungă).
Numele nu contează; după ce le urci, se leagă în `assets/app.js`, în obiectul
`PHOTOS`, de locul în care apar (Panou, ecranul de intrare, documente).

Conform brandbook-ului: lumină naturală, mâini reale, nimic pus în scenă,
fără stocuri și fără filtre.
